# translatefix

العربية · **[English](README.md)**

ترجمة النص الذي تكتبه، في مكانه، بضغطة اختصار واحدة.

```
كيف حالك اليوم     →   How are you today
How are you today  →   كيف حالك اليوم
```

حدّد النص — أو لا تحدّد شيئاً فيأخذ السطر الحالي — واضغط **Ctrl+Alt+T**، فيُستبدل
النص بترجمته. والاتجاه يُكتشف تلقائياً.

> أخت [layoutfix](https://github.com/mosabah1/layoutfix) التي تصحّح النص المكتوب
> بلغة لوحة مفاتيح خاطئة بـ **Ctrl+Alt+L**. فُصلتا عمداً: layoutfix لا تتصل
> بالشبكة إطلاقاً، وهذه مضطرة لإرسال نصك إلى طرف ثالث. شغّلهما معاً — لا تتعارض
> اختصاراتهما.

---

## التثبيت

1. نزّل `translatefix.exe` من [آخر إصدار](../../releases/latest).
2. ضعه في أي مكان وانقر عليه مرتين.
3. تظهر أيقونة قرب الساعة. بلا تنصيب، وبلا Python، وبلا مفتاح.

ولتشتغل مع ويندوز: كلك يمين على الأيقونة ← **تشغيل مع ويندوز**.

### ويندوز سيحذّرك أول مرة

الملف غير موقّع رقمياً، فيظهر **"Windows protected your PC"** — اضغط
**More info** ثم **Run anyway**. وقد تعترض بعض مكافحات الفيروسات: الأداة ترسل
ضغطات مفاتيح وتقرأ الحافظة وتتصل بالشبكة، وهذه صفات keylogger. الكود أمامك،
و[بناؤه بنفسك](#البناء-من-المصدر) أمر واحد.

## الاستخدام

| الحالة | الضغطة |
|---|---|
| النص محدد | **Ctrl+Alt+T** — يترجم المحدد |
| لا يوجد تحديد | **Ctrl+Alt+T** — يترجم السطر من بدايته حتى المؤشر |

تعمل في أي برنامج يدعم Ctrl+C / Ctrl+V — المتصفح، Word، واتساب، تيليجرام،
VS Code.

## إلى أين يذهب نصك

اقرأ هذا قبل أن تستخدمها في شيء حسّاس.

**حين تضغط الاختصار، يغادر النصُّ المحددُ جهازَك.** يُرسل عبر HTTPS إلى خدمة
الترجمة التي ضبطتها. لا مفرّ من ذلك — فهذا هو معنى الترجمة. وبالتحديد:

- **الافتراضي (`provider = google`)**: نصك يذهب إلى منفذ جوجل العام للترجمة. بلا
  حساب ولا مفتاح ولا ما يعرّف بك سوى الطلب نفسه. وهو المنفذ الذي تستخدمه أدوات
  ترجمة مجانية كثيرة، لكنه **ليس واجهة رسمية موثّقة**، فقد تحدّه جوجل أو تغيّره
  دون إشعار.
- **`provider = deepl`**: نصك يذهب إلى DeepL بدلاً عنها، ومعه مفتاحك.

**لا يُرسل شيء ما لم تضغط الاختصار.** الأداة لا تراقب لوحة المفاتيح، ولا تسجّل ما
تكتبه، وتبقى نائمة حتى يُطلق الاختصار. ولا تكتب شيئاً على القرص إلا إذا فعّلت
`debug = true`، وحتى حينها يُنقَّح مفتاحك من السجل.

**لا تستخدمها في نص لا ترضى بلصقه في موقع ترجمة عام.** كلمات المرور، المفاتيح
الخاصة، الأمور الطبية أو القانونية، وما يخضع لاتفاقية سرية. وهذا ليس عيباً في
الأداة، بل حال كل مترجم آلي.

وإن كانت هذه المقايضة غير مقبولة لعملك، فـ[layoutfix](
https://github.com/mosabah1/layoutfix) هي الأخت التي لا تتصل بالشبكة أبداً.

## الإعدادات

كلك يمين على الأيقونة ← **فتح ملف الاعدادات**، أو عدّل:

```
%APPDATA%\translatefix\settings.ini
```

| المفتاح | الافتراضي | المعنى |
|---|---|---|
| `hotkey` | `ctrl+alt+t` | الاختصار |
| `provider` | `google` | `google` (بلا مفتاح) أو `deepl` (يحتاج مفتاحاً) |
| `fallback_provider` | — | يُستخدم تلقائياً إذا فشل الأساسي |
| `deepl_api_key` | — | مفتاحك من deepl.com/pro-api |
| `lang_a` / `lang_b` | `AR` / `EN-US` | اللغتان اللتان نتنقل بينهما |
| `formality` | `default` | `default` / `more` / `less` (DeepL، لبعض اللغات) |
| `timeout` | `12` | ثواني انتظار الخدمة |
| `fallback_line` | `true` | ترجم السطر الحالي إذا لم يكن فيه تحديد |
| `notify` | `true` | اشرح الفشل برسالة بدل صوت مبهم |
| `debug` | `false` | اكتب `translatefix.log` بجانب ملف الإعدادات |

احفظ ثم أعد التشغيل. وإن بدا تعديلك بلا أثر، شغّل `translatefix.exe --check`:
يطبع ملف الإعدادات الذي يقرأه، ويقول صراحةً إن تعذّرت قراءته.

**لغات أخرى:** اضبط `lang_a` و`lang_b` على أي زوج تدعمه الخدمة — `FR`، `DE`،
`TR`، `ES`. لكن اكتشاف الاتجاه يفترض أن إحداهما عربية؛ ولغتين غير عربيتين لن
يختار الاتجاه صحيحاً بعد.

**الوضع المحمول:** ضع `settings.ini` بجانب الـ exe فيُستخدم بدلاً عنه.

### استخدام DeepL

ترجمة DeepL أفضل غالباً، وهي واجهة رسمية موثّقة لا منفذاً عاماً قد يتغيّر. تحتاج
حساباً مجانياً، لكن الباقة المجانية **رصيد لمرة واحدة** لا حصة شهرية متجددة —
فحين ينفد تتوقف الترجمة ما لم تدفع.

ولهذا وُجد `fallback_provider`:

```ini
provider = deepl
fallback_provider = google
deepl_api_key = مفتاحك هنا:fx
```

فيُستخدم DeepL ما دام الرصيد، وتنتقل الأداة بهدوء إلى جوجل حين ينفد بدل أن
تتعطل. وللتأكد من مفتاحك ورصيدك المتبقي:

```bat
translatefix.exe --check-api
```

وهو يجرّب الترجمة في الاتجاهين فعلياً، لأن قائمة DeepL للغات لم تكن تاريخياً
مطابقة لما تقبله الواجهة حقاً.

## إذا لم تعمل

الأداة تشرح سبب الفشل برسالة تسمّي البرنامج الذي كانت تعمل عليه:

| الرسالة | المعنى |
|---|---|
| لم أتمكن من قراءة النص | البرنامج لم يستجب لـ Ctrl+C، أو يعمل بصلاحيات مسؤول |
| تعذرت الترجمة | الخدمة رفضت أو تعذّر الوصول إليها — والرسالة تحدد أيهما |
| تحوّلت للمحرك الاحتياطي | فشل الأساسي فترجم الاحتياطي بدلاً عنه |
| الحافظة مشغولة | برنامج آخر يمسك الحافظة |

ولتفصيل أدق اجعل `debug = true` وأعد التشغيل؛ السجل يُكتب بجانب ملف الإعدادات.

**إذا كان البرنامج الهدف يعمل بصلاحيات مسؤول والأداة لا**، فويندوز يحجب كل إرسال
إليه (UIPI) — شغّل الأداة بصلاحيات مسؤول أيضاً.

## البناء من المصدر

تحتاج Python 3.9 أو أحدث على ويندوز. لا مكتبات خارجية للتشغيل؛ PyInstaller
و Pillow فقط للبناء والأيقونة.

```bat
pip install pyinstaller pillow
build.cmd
```

أو شغّلها من المصدر:

```bat
pythonw translatefix.py
```

### الاختبارات

```bat
python test_settings.py      ; ملف الإعدادات، مع BOM وبدونه
python test_fallback.py      ; ماذا يحدث حين تفشل خدمة (يحتاج إنترنت)
python translatefix.py --check      ; الاختصار والأيقونة والحافظة وبنى Win32
python translatefix.py --check-api  ; خدمة الترجمة نفسها
```

فئتا خلل مغطاتان هنا لأن كلتيهما وقعت فعلاً:

1. **ملف إعدادات فيه UTF-8 BOM** — وهو ما تكتبه عدة محررات على ويندوز افتراضياً —
   كان يجعل `configparser` يفشل. ثم يُبتلع الاستثناء وتُستخدم القيم الافتراضية
   بصمت، فيبدو تعديل الإعدادات بلا أثر. صارت القراءة `utf-8-sig`، والفشل يُعلَن
   لا يُخفى.
2. **`HTTPError` وريث `URLError`.** فالتقاط `URLError` أولاً يسمّي كل خطأ من
   الخادم "انقطاع إنترنت"، فيذهب المستخدم يفحص شبكته بينما المشكلة مفتاح مرفوض
   أو رصيد نفد.

أما محرك التقاط النص (إرسال المفاتيح وقراءة التحديد عبر الحافظة) فمنقول من
[layoutfix](https://github.com/mosabah1/layoutfix) حيث اكتُشفت فيه ثلاثة أخطاء
أخرى وأُصلحت. وتعليقاته تشرح سبب كل جزء — اقرأها قبل أن تبسّط شيئاً في
`copy_selection` أو `release_modifiers`.
